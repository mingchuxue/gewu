# 格物 · 元素周期表

可交互的中文元素周期表，面向中学化学学习。

- **周期表**：按分类、s/p/d/f 分区着色；电负性、电离能、原子质量、密度、熔沸点热力图；拖动温度看各元素的固液气物态
- **元素详情**：中文名与读音、相对原子质量（附课本常用取值）、周期与族、常见化合价、电子排布式、原子结构示意图、电子层模型、物性数据；键盘左右键翻看
- **相对分子质量计算**：支持括号与结晶水（如 `Fe2(SO4)3`、`CuSO4·5H2O`），给出各元素质量分数，可切换课本取值与精确值
- **记忆训练**：默写前 20 号元素计时、前 36 号速认、全表挑战
- 深浅色主题，记录保存在本机浏览器中

## 数据

- 元素性质：[Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON)
- 中文名称：全国科学技术名词审定委员会公布的元素用字
